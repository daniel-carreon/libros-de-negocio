# W. Ross Ashby — *Design for a Brain* (1952)

> Ficha de lectura: mapa para ir al libro, no sustituto. Páginas = número de página **del PDF** (el que muestra el visor, no el impreso).

## Tesis en tres líneas

1. El cerebro es una máquina determinista cuyos mecanismos pueden estudiarse mediante las herramientas de la dinámica de sistemas: variables, estados de equilibrio, estabilidad y feedback son los conceptos clave para entender la conducta adaptativa.

2. La adaptación no requiere propósito ni conciencia, sino mecanismos ultrastables que mantienen variables fisiológicas esenciales dentro de límites mediante retroalimentación interna y ajuste de parámetros ante perturbaciones externas.

3. Sistemas pequeños se adaptan por prueba-error; sistemas grandes requieren arquitectura de aislamiento parcial entre subsistemas para acumular éxitos parciales sin interferencia, y ambientes complejos exigen estructuras seriales y dispersión de estímulos en órganos sensoriales.

## Por capítulo

### Cap. 1 · The Problem (pp. 15–27)

- Reconciliación entre mecanismo cerebral (máquina física) y conducta adaptativa (aparentemente propositiva)
- Distinción entre reflejos inatos y comportamiento aprendido mediante cambio post-experiencia
- Método operacional: solo conceptos objetivamente demostrables; rechazo de explicaciones teleológicas y propiedades vitales
- Conciencia es un hecho fundamental pero no necesaria para aprendizaje

**Cita ancla** (p. 15): «How does the brain produce adaptive behaviour»

### Cap. 2 · Dynamic Systems (pp. 27–44)

- Sistema: conjunto de variables que cambian con el tiempo regidas por relaciones determinadas
- Variable: cantidad medible con valor numérico definido en cada instante
- Espacio de fases: representación gráfica de todas las transiciones posibles del sistema bajo condiciones constantes
- Campo: mapa completo de líneas de comportamiento mostrando evolución desde cualquier estado inicial

**Cita ancla** (p. 28): «A variable is a measurable quantity»

### Cap. 3 · The Organism as Machine (pp. 44–57)

- Organismo es materia común, especificable mediante variables medibles (movimientos, temperatura, voltaje neural)
- Sistema organismo-ambiente es determinado por estados: dado estado inicial y condiciones, transición es única
- Feedback crucial: receptores afectan músculos vía sistema nervioso; músculos afectan receptores vía ambiente
- Variables esenciales: fisiológicas ligadas a supervivencia que deben mantenerse dentro de límites

**Cita ancla** (p. 52): «In most cases the change which induces a reaction is brought»

### Cap. 4 · Stability (pp. 58–72)

- Estabilidad es propiedad del sistema completo, no de materiales individuales
- Equilibrio: punto del que no emerge movimiento; región estable si líneas de comportamiento quedan dentro
- Feedback negativo logra estabilidad activa: desplazamiento genera fuerzas de retorno (péndulo, Watt governor)
- Estabilidad no puede asignarse a partes separadas; ejemplo termostato requiere coordinación

**Cita ancla** (p. 60): «state of equilibrium is one from which the»

### Cap. 5 · Adaptation as Stability (pp. 72–110)

- Adaptación operativamente definida: comportamiento mantiene variables esenciales dentro de límites fisiológicos
- Homeostasis: mecanismos inatos mantienen glucosa, temperatura, CO₂, luminosidad retinal
- Generalización: gato adulto aprende mantener distancia del fuego; humano usa casa, ropa, auto
- Coordinación motora medible como desviación mínima desde línea estándar

**Cita ancla** (p. 76): «not acting homeostatically for skin temperature»

### Cap. 6 · Parameters (pp. 84–99)

- Parámetro: variable controlada externamente pero constante durante operación primaria del sistema
- Distinción variable-parámetro es funcional, no absoluta; mismo factor puede ser ambos
- Estímulo: parámetro que cambia valor discontinuamente
- Parámetros enlazan ambiente con sistema, permitiendo cambios externos desencadenen reacciones

**Cita ancla** (p. 82): «curves were drawn with the respective hands»

### Cap. 7 · The Ultrastable System (pp. 99–100)

- Doble retroalimentación: interna mantiene sistema estable; externa ajusta parámetros ante perturbaciones desconocidas
- Mecanismo de step-function: cambios discontinuos cuando se alcanzan umbrales críticos
- Sistema ultrastable combina feedback interno y ajustes por saltos para alcanzar estabilidad global

**Cita ancla** (p. 99): «What has been deduced so far in this Chapter is necessary»

### Cap. 8 · The Homeostat (pp. 100–122)

- Máquina experimental de cuatro bucles acoplados con step-functions y selectores para ajustes
- Cada bucle contiene resistencias ajustables; selector elige nueva configuración al azar cuando desviación supera límite
- Entrenamiento: perturbaciones sucesivas fuerzan selectores a cambiar hasta encontrar configuración estable
- Una vez hallada estabilidad, transiciones adicionales no son requeridas

**Cita ancla** (p. 100): «We assume that we have before us»

### Cap. 9 · Ultrastability in the Organism (pp. 122–138)

- Sinapsis neurales pueden cambiar polaridad (activar o inhibir) proporcionando base biológica para step-mechanisms
- Memoria posiblemente es cambio permanente en sinapsis; múltiples niveles de feedback (espinal, bulbar, cortical, neocórtex)
- Gen-patrón controla factores generales del desarrollo (~50 mil genes para 10¹⁰ neuronas) no detalles sinapsis individuales
- Cerebro es ultrastable biológicamente, capaz de ajustes sin programa genético detallado

**Cita ancla** (p. 122): «We can now appreciate how different an ultrastable system»

### Cap. 10 · The Recurrent Situation (pp. 138–155)

- Situación recurrente: problema se repite y respuesta útil primera vez es útil después
- Sin mecanismo especial, homeostat pierde adaptación previa cuando problema recurre (inhibición retroactiva)
- Grand Disturbance: perturbación lifelong; Grand Response: respuesta lifelong adaptada para mantener variables esenciales
- Acumulación de adaptaciones requiere canales funcionales separados selectivamente abiertos según problema

**Cita ancla** (p. 139): «A simple circuit if excited would tend»

## Para Daniel

Este libro construye la teoría detrás del diagnóstico RACE y la máquina cerebral del Acompañamiento: el concepto de **variables esenciales** (ingresos, estrés del consultor, burnout) es idéntico al de Ashby, igual que el **feedback doble** (mediciones internas + ajustes según cliente). En el diagnóstico, Daniel busca el "muro de constancias" —separación funcional entre subsistemas del negocio (ventas, operaciones, producto)— que permite acumular mejoras sin retroactive inhibition. Caps. 15–16 explican por qué la adaptación serial por clientes (primero descubrir problema, luego solucionar, luego escalar) es exponencialmente más rápida que intentar todo simultáneamente.
